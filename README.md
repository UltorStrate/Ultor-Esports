# ULTOR ESPORTS — Shop-Grundgerüst

## Dateien
- `index.html` — Seitenstruktur und Inhalte
- `style.css` — Dark-Esports-Design und responsive Layout
- `script.js` — Navigation und Demo-Warenkorb

## Lokal starten
1. ZIP entpacken.
2. `index.html` doppelklicken.
3. Die Website öffnet sich im Browser.

Es ist kein Build-Schritt und kein lokaler Server notwendig.

## Aktueller Stand
Dies ist ein Frontend-Prototyp. Der Warenkorb ist eine reine Demo:
- keine echten Bestellungen
- keine Zahlungsabwicklung
- keine Bestandsverwaltung
- keine Speicherung zwischen Geräten

Die Trikotgrafik ist derzeit eine CSS-Platzhalterillustration und muss später durch echte ULTOR/NOKTO-Produktbilder ersetzt werden.

## Vor einem echten Verkaufsstart
- Hersteller, Einkaufspreis, Verkaufspreis und Lieferzeiten festlegen
- echte Produktfotos und Größentabelle ergänzen
- Bestell- und Zahlungsbackend integrieren
- Impressum, Datenschutz, Widerruf, Versand- und Zahlungsinformationen rechtlich korrekt ergänzen
- Domain und Hosting einrichten

## Anpassungen
Farben stehen am Anfang von `style.css` in `:root`.
